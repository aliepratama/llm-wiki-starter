# Contributing to LLM Wiki Starter

First off, thank you for considering contributing to this project! It's a personal project, but community contributions are highly welcomed.

## How to Contribute

1. **Fork** the repository.
2. **Create a branch** for your feature or bug fix:
   `git checkout -b feat/your-feature-name` or `git checkout -b fix/your-bug-fix`
3. **Commit your changes**. Use clear and descriptive commit messages (e.g., `Feat: add markdown parser module`).
4. **Push to your branch**: `git push origin feat/your-feature-name`
5. **Open a Pull Request (PR)** against the `main` branch of this repository.

## Rules for Pull Requests
- Keep your PR focused on exactly one feature or bug fix.
- Ensure you don't break the core `raw/`, `wiki/`, and `outputs/` logic.
- If you are adding a new AI behavior, consider placing it in the `modules/` directory rather than rewriting `AGENTS.md`.

Thank you for helping make this setup better!
